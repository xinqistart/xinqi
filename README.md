## 🚀 项目简介

【鑫启商城】全网首个一套代码覆盖单商户、多商户、多租户，且包含跨境功能的微服务架构开源商城。采用SpringCloud+Vue3等流行框架，覆盖多业务场景：B2B2C、S2B2C、B2C、SAAS多模式商城， 包含多端：小程序、H5、APP、PC，包含丰富的营销功能：拼团、秒杀、分销、套餐赠品、优惠券、满减折、多商家、直播、装修、跨境电商等功能，满足企业级商用需求。
覆盖电商领域八大标准化解决方案
多商户云市场系统(支持SaaS化部署)
开源跨境版(MIT协议永久免费)
SaaS化专业版(多租户模式)
跨境贸易解决方案(多语言/多币种)
社交化分销系统(三级裂变+佣金体系)
直播电商引擎(实时连麦，点赞互动)
智能收银中台(聚合支付+电子发票)
。

## ✨ 核心特性

- **🎯 多模式支持**: 一套代码支持 B2B2C、S2B2C、B2C、SAAS 多模式商城
- **🌍 跨境电商**: 内置多语言、多币种跨境贸易解决方案
- **📱 全端覆盖**: 支持小程序、H5、APP、PC 多端适配
- **🛠 微服务架构**: 基于 SpringCloud Alibaba 的分布式架构
- **🎨 丰富营销**: 拼团、秒杀、分销、直播等完整营销体系

## 🏗 技术架构

### 后端技术栈
- **框架**: Spring Boot 3.x + Spring Cloud Alibaba
- **安全**: Spring Security + JWT
- **数据库**: MySQL + Redis + Elasticsearch
- **消息队列**: RabbitMQ/RocketMQ
- **注册中心**: Nacos
- **配置中心**: Nacos Config
- **网关**: Spring Cloud Gateway
- **监控**: Spring Boot Admin + SkyWalking

### 前端技术栈
- **框架**: Vue 3 + TypeScript
- **构建工具**: Vite
- **UI 组件**: Element Plus
- **状态管理**: Pinia
- **路由**: Vue Router 4
